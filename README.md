# Swiggy Data Analysis using SQL Server

## Project Overview
This project analyzes Swiggy restaurant and dish data using SQL Server.

## Skills Used
- SQL Server
- Data Cleaning
- Data Modeling
- Star Schema
- Window Functions
- Business Analysis

## Database Design

### Dimension Tables
- dim_date
- dim_location
- dim_restaurant
- dim_category
- dim_dish

### Fact Table
- fact_swiggy_orders

## Analysis Performed
- Rating Distribution
- Restaurant Performance
- Cuisine Analysis
- Location Analysis
- Popular Dishes
